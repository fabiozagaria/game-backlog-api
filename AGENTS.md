# Istruzioni per assistenti AI

## Scopo
Repository Spring Boot dedicato a un esercizio/progetto Game Backlog. Lo stato funzionale non è completamente documentato nel repository.

## Regole operative
- Prima di proporre modifiche, ispezionare `src`, `pom.xml` e `docs/CONTEXT.md`.
- Non inventare endpoint, modelli o funzionalità non presenti nel codice.
- Trattare il repository come laboratorio finché README e comportamento non documentano uno stato più maturo.
- Se usato per studio, privilegiare review, debugging e indizi minimi.

## Fonti di verità
- Il codice e `pom.xml` sono la verità tecnica.
- `docs/CONTEXT.md` dichiara ciò che è verificato e ciò che resta incerto.
- Roadmap didattica, voti e ripassi restano in Notion.

## Sicurezza
Non inserire credenziali, token, segreti o dati personali.
